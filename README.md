### RAGE Light Editor

A standalone tool for editing the lights inside GTA V models (`.ydr` / `.yft`) with an in-game accurate preview.
Instead of checking every change in-game, open the file, see the lighting exactly as GTA V renders it, edit, save, done.

### Features

- **In-Game Lighting** — Open YDR and YFT files and work with point, spot, and capsule lights using the RAGE lighting system.
- **Import & Export** — Import multiple YDR and YFT files at once, so you can load your shell and light proxies together, link lights to the props you want, and export everything when you're done.
- **Light Controls** — Edit colour, intensity, falloff, spot cone, corona, volume, flags, active hours, and other supported parameters.
- **Real-Time Light Effects** — See lighting and light effects update instantly as you adjust the lights.
- **Real-Time Shadows** — Preview shadows directly in the viewport with adjustable softness and per-light controls.
- **IES & Gobo Textures** — Project custom textures and patterns through spotlights and see them in real time.
- **Light Gizmos** — Move and rotate lights using familiar 3D-program-style controls.
- **Multi-Light Editing** — Duplicate, instance, copy/paste settings, and edit multiple lights at once.
- **Walk-Through Mode** — Move through interiors using the arrow keys for easier light placement.
- **Day/Night Preview** — Change the time of day to preview how the lighting looks at different hours.
- **Interior Import** — Load an MLO's `.ytyp` and automatically place every prop exactly where GTA V puts it.
- **Prop Lights** — Props with lights appear in the Props list, editable in place and saveable back to their own file.
- **Extra Prop Folders** — Point the editor to your prop folders when something's missing, then reload.
- **Projects** — Save your whole setup (models, interior, folders, timecycle, camera) in one file and reopen it in a click.
- **Weather** — Every GTA V weather cycle, straight from your installation. Starts on `w_clear`.
- **Interior Timecycles** — Approximately 1,000 interior modifiers with a strength slider. Importing an interior automatically picks the appropriate one.

### Installation
1. Download the latest version from the **Releases** section.
2. Extract the downloaded archive.
3. Launch `RAGE Light Editor.exe`.
4. Load your YDR, YFT, or YTYP files and start editing.

## Preview Accuracy
The lighting preview is designed to be as close as possible to the final GTA V result.

> **Note:** The preview may not always be 1:1 with the final in-game result, as GTA V's Timecycle system also affects how lighting is displayed in-game.
